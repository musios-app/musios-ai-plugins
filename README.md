# musios AI plugins

Installers for the [musios.app](https://musios.app/) AI skills, for the ChatGPT desktop app's *Add plugin marketplace*.

These are AI plugins (skills for an AI assistant), not audio plugins.

## Install in ChatGPT

1. Open the ChatGPT desktop app (Mac or Windows).
2. Plugins > Add plugin marketplace > Source: `musios-app/musios-ai-plugins`
3. Install the plugin you want from *musios AI*.
4. Open a new chat in **Work** mode (skills run only there).
